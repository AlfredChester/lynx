# Lynx

[中文帮助指南](./README_CN.md)

Un repositorio de herramientas para casos de prueba impulsado por [Cyaron](https://github.com/luogu-dev/cyaron/)

## Características

- Inicializar un directorio de problema de lynx.
- Generar casos de prueba para problemas.
- Exportar los datos a diferentes formatos que pueden ser reconocidos por múltiples OJs.
- Comparar la salida de dos programas utilizando una descripción de problema de lynx.
- Generar datos sencillamente en solo cinco minutos.

## Instalación

Lynx está disponible en PyPI, puedes instalarlo ejecutando:

```bash
pip install pyLynx
```

## Uso

Lynx tiene tres subcomandos por ahora, que son `lynx init`, `lynx generate` y `lynx compare`. Puedes usar `lynx [command] --help` para obtener información de ayuda.
